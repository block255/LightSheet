# LightSheet
A compact, free, and clean spreadsheet software developed with DeepSeek on DSH. Offers basic file editing and script-based calculation operations (macros not included).

## 使用说明 / How to Use

zip 打包版本解压缩后，找到文件夹里的 exe 文件（轻量表格.exe），双击即可打开软件。

After extracting the zip release, find the exe file (轻量表格.exe) in the folder and double-click it to launch the software.
